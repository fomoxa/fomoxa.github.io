Ecosystem · September 2026

One specification. Many implementations.

The specification is Fomoxa. Everything else on this page is a tool that helps you use it, or a sample of how it can be implemented. All of it is stable and usable today.

Layers

What is the protocol, and what is not

Protocol Specification · RFC-0001, 0002, 0003 The only definition of Fomoxa. v1.1.0, Final. If anything below disagrees with it, the specification wins.
Tool fomoxac · fomoxa-inspect Generates codecs from annotated types in eight languages, checks schema compatibility, and decodes payloads for debugging.
Samples Runtime implementations Framing, schema handshake and heartbeat over TCP/UDP, following the implementation guide. Examples of how Fomoxa can be carried, not part of the specification.

Replace any of these with your own and the wire format holds. A hand-written codec that passes 100% of the RFC-0003 vectors is exactly as Fomoxa Compatible as a generated one.

Tools

fomoxac

One source generator for eight languages. It reads annotations, writes plain source, and exits. The generated code has no runtime dependency.

fomoxac generate Annotations in, codec source out Reads annotated model types in one of eight languages and writes the generated codec, a schema.json, and a build-graph.json. Never fails on a breaking change - it reports the change and generates anyway.
fomoxac compat Schema compatibility check Compares a base schema against the current source tree, or against another schema file, and prints a compatibility report. Exits non-zero on a breaking verdict.
fomoxac ci A gate for pull requests Confirms the committed schema.json matches the branch's source, then compares it against the target branch's schema over git. Fails the build on drift or a breaking change.
fomoxa-inspect Decode a payload by hand Reads a raw byte stream, from a file or hex on the command line, against a schema.json and prints every field with its offset and its bytes. Ships in the same binary as fomoxac.

tests/vectors/fomoxa-vectors.json is the cross-language reference: fixed bytes and fixed fingerprints every backend is expected to reproduce. The Rust backend checks it byte for byte in CI, and cross-language tests pin the same fingerprint for the same model written in different languages.

Samples

Runtime implementations

Each one carries opaque payloads: framing, schema handshake, heartbeat and a non-blocking tick loop over TCP or UDP. None contains a codec. Codecs come from fomoxac.

Interop means the runtime is part of fomoxa/interop: two processes in different languages complete a handshake over a real TCP or UDP socket and exchange a message. The Godot runtime has its own test suite and CI, but is not yet in that matrix.
